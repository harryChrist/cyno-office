# Ícones do Cyno Office

Os ícones desta pasta foram gerados a partir de `brand/cyno/final/png/cyno-tile-512.png` e `brand/cyno/final/favicon.ico`.

Para regenerar todos os tamanhos (inclusive `.icns` e logos da Microsoft Store) com a CLI do Tauri:

```bash
cd packages/desktop
npx tauri icon ../../brand/cyno/final/png/cyno-tile-512.png
```
